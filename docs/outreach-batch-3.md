# Outreach batch 3: UK NHS, Healthwatch, hospices and councils, plus the US, Canada and New Zealand

Researched 8 September 2026. 40 organisations with an email address seen on
their own website (24 in the UK, 16 outside it) and 21 that accept contact
only through a web form. None appear in batch one or two. Ireland and
Australia are not covered because that research run failed part way; they
are the first job for batch four.

Same rule as batch two: every email asks for one thing only, a link to the
free guides. No packages, no prices, no pitch. The service is in the
signature and nowhere else. For targets outside the UK, link the global
guide versions and do not say "in the UK".

Three NHS addresses were decoded from the trust's own page code because the
page hides them from scrapers. They are marked "check on the page first".
Open the page in a browser and confirm the address before sending.

Nothing in this batch has been sent yet.

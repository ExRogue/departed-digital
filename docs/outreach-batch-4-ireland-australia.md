# Outreach batch 4: Ireland and Australia

Researched 10 September 2026, the run that failed part way in batch three. 28
organisations with an email address seen on their own website (13 in Ireland, 15
in Australia) and 20 reachable only by web form. None appear in batches one to three.

Same rule as before: every email asks for one thing only, a link to the free
guides. No packages, no prices, no pitch. The service is in the signature and
nowhere else. All guide links are the global versions, and no email says
"in the UK".

Three entries need a look first. The Irish Childhood Bereavement Network address
was decoded from the page's own Cloudflare protected code, so confirm it in a
browser. Palliative Care ACT and Solace Grief Support have a confirmed email but
an unconfirmed page. Many Irish and Australian sites block automated checks or
refuse connections from outside the country, so several strong targets sit in
the form only list purely because the site would not open.
